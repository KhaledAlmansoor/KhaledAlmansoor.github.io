# Khaled Almansoor

Personal site of Khaled Adel Almansoor, cybersecurity graduate focused on network defense.

Live: https://khaledalmansoor.github.io/

- Single `index.html`, no build step. English and Arabic (RTL) with a toggle that remembers the choice; `?lang=ar` opens the Arabic version directly.
- Fonts: IBM Plex Sans, IBM Plex Sans Arabic, IBM Plex Mono (Google Fonts).
- `og.png` is the link preview card for WhatsApp, X, and LinkedIn.
- To add a LinkedIn link, set `LINKS.linkedin` near the bottom of `index.html`; empty links stay hidden.
